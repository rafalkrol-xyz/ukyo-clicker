# Ukyo Clicker

## Overview

A foreground Rust CLI for macOS on Apple Silicon. It reads a paired right Joy-Con through raw IOKit HID
and turns button presses into Right/Left arrow keystrokes for presenterm running in Ghostty.

Ukyo (possibly after 右京 [ukyou, うきょう], meaning the right [part of a] capital [city])
was apparently the codename for the right Joy-Con.

## Prerequisites

* [the right Nintendo Switch Joy-Con](https://www.nintendo.com/us/store/products/joy-con-r-neon-red/)
